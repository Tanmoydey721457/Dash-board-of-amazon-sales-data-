# Project Title---
Amazon Sales Data Dashboard (Power BI)

# Description----
This interactive Power BI dashboard analyzes Amazon sales data across multiple dimensions such as shipping modes, countries, cities, categories, and markets. It provides insights into sales performance, profitability, and shipping costs.
 ## Key Features----
- 📊 **KPIs:** Total Quantity, Sales, Profit, and Shipping Cost
- 🚚 **Sales by Ship Mode:** Standard Class, Second Class, First Class, Same Day
- 🌍 **Sales by Country:** Egypt, Morocco, South Africa, DRC, Nigeria
- 🏙️ **Sales by City:** Kinshasa, Casablanca, Alexandria, Johannesburg, etc.
- 🗂️ **Sales by Category:** Office Supplies
- 🌐 **Sales by Market:** Africa
##  Visuals Included----
- **Cards:** Show KPIs (Quantity, Sales, Profit, Shipping Cost)
- **Line Chart:** Sales by Ship Mode
- **Bar Chart:** Sales by Country and City
- **Donut Chart:** Sales by Category and Market
## How to Use---
1. Clone this repository.
2. Open the `.pbix` file in Power BI Desktop.
3. Explore filters (Category, Market) to interact with the dashboard.

## About the Dataset---
The dataset represents Amazon sales transactions with details on quantity, sales, profit, shipping cost, category, market, country, and city.
